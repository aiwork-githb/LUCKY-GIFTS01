# Список основных 3D assets

> Приоритет: **P0** — нужен для vertical slice (Глава 1) или как фундамент; **P1** — нужен к своей главе; **P2** — полировка и разнообразие.
> «Tris» — LOD0 для не-Nanite; для Nanite указан ориентир исходной плотности. «Tex» — текстурный набор (BC/N/ORM[/E/M]).
> Phase — когда ассет производится (см. [Roadmap](08_Roadmap.md)).

## 0. Стандарты качества (для всех ассетов)

- Реальный масштаб, применённые трансформы, pivot по правилам kit-а.
- Чистая топология: квады для деформируемых и подразделяемых мешей; для статики — без лишних петель, без n-gons в экспорте.
- UV без растяжений, тексель по категории (архитектура 512 px/м, пропы 1024 px/м, герои 2048 px/м).
- PBR: BaseColor без запечённого света, корректные диапазоны (металл 0/1, roughness с вариацией), normal в DirectX-конвенции, AO в ORM.
- Износ, грязь и история использования **на каждом** ассете: сколы на углах, потёртости там, где касались руки, подтёки под болтами.
- LOD0–3 или Nanite + коллизия. Ревью в 6 сценах освещения `L_Test_LookDev`.

## 4. Modular environment kits

**Сетка:** 50 см. Базовый модуль стены — 400 × 400 см (+ 200 и 100 по ширине; высоты 400 / 800 / 1200). Все модули стыкуются без зазоров, pivot — в углу сетки. Каждый kit — Nanite + trim sheet + 2–3 варианта износа (Clean / Worn / Damaged) через MI и vertex paint, а не отдельные меши.

## 9. Порядок производства (по качеству-критичности)

1. **VERITY-0** (Phase 3) — эталон качества всего проекта: топология, материалы, риг, анимации.
2. **Shared kit + Kit гл. 1** (Phase 4) — эталон окружения: сетка, trim sheets, износ.
3. **Фонарь, руки, табельные часы, двери, щит питания** (Phase 5) — то, что игрок видит вплотную.
4. **Фонарщик + hero-станки гл. 1** (Phase 6).
5. Далее — по главам.
