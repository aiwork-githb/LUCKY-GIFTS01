# Roadmap разработки

> Правило фаз: **не переходим дальше, пока фундамент текущей фазы не работает.** Каждая фаза заканчивается проверкой (запуск, тесты, ревью), исправлением найденного и коммитом. Где нужно ручное действие — работа останавливается с инструкцией: что сделать, где, что нажать, что должно получиться.

### Внутренний цикл каждой главы (Phases 6, 8–11)

```
1. Грейбокс (Modeling Tools / kit-блоки) + проход геймплея «в кубах»
2. Геймплей-пасс: головоломки, ИИ, погони — играбельно и интересно уже в грейбоксе
3. Арт-пасс: kit, пропы, декали, сторителлинг комнат
4. Свет-пасс: мотивированный свет, атмосфера, VFX
5. Звук-пасс: эмбиент-зоны, музыка, отпечатки врагов
6. Катсцены: shot list → Sequencer
7. Тест: проход, perf, soft-lock, кривая напряжения → исправления
```

Если грейбокс неинтересен — арт-пасс не начинается.

## ⚠️ Ручные действия перед Phase 2

Unreal Editor не запускается в облачном контейнере, а Unreal MCP подключается к редактору на твоём компьютере. Поэтому с Phase 2 Claude Code должен работать **локально, на твоём PC**, в папке этого репозитория.

### Шаг 1. Установить Unreal Engine 5
1. **Что сделать:** установить Epic Games Launcher и последнюю стабильную версию Unreal Engine 5.x.
2. **Где:** сайт epicgames.com → «Download» (Epic Games Launcher) → установить → войти в аккаунт Epic.
3. **Что нажать:** в Launcher слева **Unreal Engine** → сверху **Library** → «+» рядом с **ENGINE VERSIONS** → выбрать последнюю 5.x → **Install**. В **Options** оставить платформу Windows; «Editor symbols for debugging» — по желанию (это десятки GB).
4. **Что должно получиться:** в Library появилась версия движка с кнопкой **Launch**, редактор открывается из Launcher.

### Шаг 2. Установить Visual Studio 2022 (для C++)
1. **Что сделать:** установить Visual Studio 2022 Community с инструментами для C++ и Unreal.
2. **Где:** visualstudio.microsoft.com → **Download Visual Studio** → Community 2022 → запустить Visual Studio Installer.
3. **Что нажать:** отметить workloads **Desktop development with C++** и **Game development with C++**. Справа, в деталях Game development, отметить **Unreal Engine installer** / **IDE support for Unreal Engine** и последний **Windows 10/11 SDK** → **Install**. Точную версию MSVC для твоей версии UE сверь со страницей Epic «Setting Up Visual Studio» для этой версии.
4. **Что должно получиться:** в Visual Studio Installer оба workload-а помечены как установленные.

### Шаг 3. Git, Git LFS и клон репозитория
1. **Что сделать:** установить Git (Git LFS входит в Git for Windows) и клонировать репозиторий в **короткий путь без пробелов и кириллицы** (UE не любит длинные пути).
2. **Где:** git-scm.com → Download for Windows → установить с настройками по умолчанию. Затем открыть терминал (PowerShell).
3. **Что нажать / ввести:**
   ```powershell
   git lfs install
   git clone https://github.com/aiwork-githb/LUCKY-GIFTS01.git D:\Dev\Verity
   cd D:\Dev\Verity
   git checkout claude/jolly-pascal-kadx5t
   ```
4. **Что должно получиться:** в `D:\Dev\Verity` лежат `Docs/`, `CLAUDE.md`, `README.md`; `git lfs version` печатает версию.

### Шаг 4. Blender
1. **Что сделать:** установить актуальный стабильный Blender (4.x LTS или 5.x).
2. **Где:** blender.org → **Download**.
3. **Что нажать:** скачать установщик для Windows → установить.
4. **Что должно получиться:** Blender запускается. *(Опционально, но рекомендую: Blender MCP — аддон и MCP-сервер, чтобы Claude Code управлял открытым Blender. Установи по README выбранного сервера; проверка — шаг 6.)*

### Шаг 5. Claude Code локально
1. **Что сделать:** установить Claude Code на PC.
2. **Где:** Claude desktop app (вкладка **Code**) или CLI — инструкция на code.claude.com/docs.
3. **Что нажать:** открыть папку `D:\Dev\Verity` как рабочую директорию (в desktop app — выбрать папку; в CLI — запустить `claude` из этой папки).
4. **Что должно получиться:** Claude Code видит `CLAUDE.md` и документы в `Docs/`.

### Шаг 6. Unreal MCP (после создания проекта — первый шаг Phase 2)
`.uproject` ещё не существует: его создаст Phase 2. Поэтому порядок такой:
1. **Что сделать:** в локальном Claude Code попросить: «Начинай Phase 2». Claude создаст каркас проекта (`Verity.uproject`, `Source/`, `Config/`, `.gitattributes`). Потом ты один раз откроешь проект, установишь плагин Unreal MCP и зарегистрируешь сервер в Claude Code.
2. **Где:** двойной клик по `Verity.uproject` → на вопрос о пересборке модулей ответить **Yes**. Плагин Unreal MCP положить в `D:\Dev\Verity\Plugins\` по README выбранного сервера. Регистрация сервера — командой `claude mcp add …` из его README.
3. **Что нажать:** в редакторе **Edit → Plugins** → убедиться, что MCP-плагин и **Python Editor Script Plugin** включены → перезапустить редактор.
4. **Что должно получиться:** в Claude Code команда `/mcp` показывает Unreal-сервер (и Blender-сервер, если ставил) в статусе **connected**. После этого я проведу аудит его инструментов.

**Если у тебя уже есть предпочтительный Unreal MCP-сервер** — напиши, какой именно, и я подстрою Phase 2 под его возможности.

### Шаг 7 (облако, опционально). Сохранить Blender в облачных сессиях
Чтобы в каждой новой облачной сессии был headless Blender: меню облачного окружения в заголовке сессии → **Edit** → в setup script добавить:
```bash
python3.11 -m venv /opt/bpyenv && /opt/bpyenv/bin/pip install -q bpy
```

### Шаг 8. Квота Git LFS
Проверь лимиты хранилища и трафика LFS в настройках GitHub (Settings → Billing / Plans для аккаунта или организации). Проект будет весить десятки GB. Если лимита не хватит, нужен пакет LFS или другой LFS-хостинг до начала Phase 3.
