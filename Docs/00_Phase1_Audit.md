## 2. Unreal Engine MCP

| Проверка | Результат |
|---|---|
| Unreal MCP tools в этой сессии | **Не подключены.** Поиск по инструментам (`unreal`) ничего не нашёл |
| Подключённые MCP-серверы | `github`, `Context7` (документация), `Claude_Docs`, `claude-code-remote`. Плагин `design` не смог подключиться (403 на прокси), но для игры он не нужен |
| Unreal Editor | **Не установлен.** Это облачный Linux-контейнер: 4 vCPU, 15 GB RAM, без GPU |

Unreal Editor 5.x нужны GPU с DX12/SM6, порядка 100+ GB на диске и вход в аккаунт Epic. Запустить его в облачном контейнере на практике нельзя. Поэтому вся работа внутри Unreal Editor (Phase 2 и дальше) пойдёт **на твоём PC**. Там Claude Code должен быть запущен локально, а Unreal MCP подключён к открытому редактору. Пошаговая инструкция — в `08_Roadmap.md`, раздел «Ручные действия перед Phase 2».

## 3. Blender

| Проверка | Результат |
|---|---|
| Blender MCP (live-подключение к Blender с GUI) | **Не подключён** |
| Blender в контейнере | Системного нет. **Установлен headless Blender 5.0.1** как Python-модуль `bpy` (venv на Python 3.11 в scratchpad) |
| Тест рендера | Cycles (CPU) — ✅ отрендерил тестовую сцену в PNG |
| Тест экспорта | FBX — ✅, glTF/GLB — ✅ |
| Не проверено | EEVEE (без GPU, скорее всего, не работает), бейк текстур (проверим в Phase 3) |

Что это значит на практике:

- **Можно уже сейчас, в облаке.** Процедурное моделирование скриптами (blockout, modular kit, VERITY), UV, бейк карт через Cycles, экспорт FBX, превью-рендеры для ревью. Результат коммитится в репозиторий через LFS.
- **Нужен локальный Blender (лучше с Blender MCP).** Финальная ручная доводка: скульпт, ревью вьюпорта, полировка весов скина, интерактивный ретопо.
- headless Blender живёт только внутри текущей сессии. Чтобы он был в каждой новой облачной сессии, добавь в setup script окружения (меню облачного окружения в заголовке сессии → Edit):
  ```bash
  python3.11 -m venv /opt/bpyenv && /opt/bpyenv/bin/pip install -q bpy
  ```

## 4. Итоговое разделение работы

| Тип работы | Где выполняется |
|---|---|
| Дизайн-документы, сюжет, архитектура, C++-код систем (написание и ревью) | Облако или локально |
| Процедурные 3D-ассеты, бейк, экспорт FBX, превью-рендеры | Облако (headless Blender) или локально |
| Создание `.uproject`, компиляция C++, импорт ассетов, уровни, материалы, Sequencer, плейтест, профилирование | **Только локально**: твой PC + Unreal Editor + Unreal MCP |

C++ можно писать и в облаке, но компилировать и проверять его нужно в UE. Поэтому системный код идёт в репозиторий только после компиляции и теста в редакторе. Это правило качества из `CLAUDE.md`.
