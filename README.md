# VERITY: HOLLOW SUN

*VERITY never lies. Do you?*

Оригинальная сюжетная PC horror game из 5 глав на Unreal Engine 5. Ноябрь 1999 года. Техник по спасению архивов входит в запечатанный комплекс Solace Lightworks за несколько часов до затопления долины. Там Роуэна ждёт VERITY — жёлтая сфера, которая не умеет лгать и говорит детским голосом самого Роуэна.

**Статус:** Phase 1 — дизайн и архитектура завершены. Следующая — Phase 2 (базовый Unreal-проект, нужно локальное окружение).
