# CLAUDE.md — VERITY: HOLLOW SUN

Оригинальная PC horror game на Unreal Engine 5 (C++ + Blueprints). Кодовое имя проекта — `Verity`.
Пользователь общается по-русски — отвечай по-русски, технические термины можно оставлять на английском.

## Источники правды
- `Docs/01_GDD.md` — видение, столпы, механики (обзор)
- `Docs/02_Story.md` — сюжет со спойлерами, лор, глоссарий
- `Docs/03_Characters_and_Enemies.md` — VERITY (спека модели, рига, анимаций), враги и ИИ
- `Docs/04_Locations.md` — зоны по главам
- `Docs/05_Gameplay_Systems.md` — спецификации систем
- `Docs/06_Technical_Architecture.md` — модули, классы, конвенции имён, пайплайн, бюджеты, журнал решений
- `Docs/07_Asset_List.md` — список ассетов и стандарты качества
- `Docs/08_Roadmap.md` — фазы и критерии выхода

Расходишься с документом — сначала обнови документ (или запиши решение в журнал решений `06 §17`), потом меняй реализацию.

## Правила работы
- **Фазы последовательны.** Не начинай следующую фазу, пока не выполнен Definition of Done текущей (`08_Roadmap.md`).
- **Сначала изучи, потом меняй.** Прочитай код, ассеты и уровень (через Unreal MCP) перед правкой. Не удаляй и не переписывай рабочие системы без причины.
- **Маленький шаг → проверка → коммит.** После значимого изменения: компиляция, PIE или тест, скриншот или лог, и только потом коммит.
- **Качество > скорость.** Placeholder в релизном контенте запрещён. Временное помечай `// TODO(Verity): …` или записью в `Docs/TODO.md`.
- **Нужно ручное действие пользователя** — остановись и напиши: 1) что сделать, 2) где, 3) что нажать, 4) что должно получиться.
- **Оригинальность.** Не копируй персонажей, карты, музыку и сцены существующих игр (особенно Poppy Playtime). Чек-лист — `02_Story.md §11`.

## Архитектура (кратко)
- Модули: `Verity` (игра), `VerityCore` (фреймворк), `VerityAI`, `VerityUI` (CommonUI), `VerityEditor` (валидаторы).
- Связь систем — `UVerityEventBus` на GameplayTags и интерфейсы; жёстких ссылок между системами нет.
- Всё stateful реализует `ISaveableActor` + `USaveableComponent` (стабильный GUID).
- ИИ: AIPerception + StateTree (логика в C++) + EQS. **ИИ не знает позицию игрока вне перцепции и LKP.**
- Уровни: persistent на главу + стриминговые подуровни зон (`L_ChN_ZNN_Name` и `_GP`), One File Per Actor. World Partition не используется.
- Бюджеты производительности — `06 §12`. Изменение, которое их нарушает, не мержится.

## Конвенции
- Префиксы ассетов и структура `Content/` — `06 §3.1, §4`. PascalCase, без кириллицы и пробелов в именах ассетов.
- C++ — Epic coding standard. Теги иерархические: `Item.Key.*`, `Power.Circuit.*`, `AI.State.*`, `Story.Flag.*`, `Puzzle.*`.
- Исходники DCC — `Art/Source/`, экспорт — `Art/Export/`, скрипты Blender — `Tools/Blender/`, скрипты UE — `Tools/Unreal/`.
- Бинарные файлы — только через Git LFS (`.gitattributes`).
- Коммиты: `[PhaseN] Область: что сделано`.

## Окружение
- Облачная сессия: Unreal Editor недоступен. headless Blender — через `bpy` (Python 3.11 venv); если его нет, установи: `python3.11 -m venv <dir> && <dir>/bin/pip install bpy`.
- Работа в Unreal Editor (Phase 2+) — локально, через Unreal MCP. Реальный список MCP-инструментов — `Docs/Tools_UnrealMCP.md` (создаётся в Phase 2).
